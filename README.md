# Node.js Graphql
GraphQL service for interacting with data and providing a flexible interface for queries. This project was created while studying at RS SHOOL https://rs.school/ NodeJS 2024Q3.

## Stack:
* Node.js
* TypeScript
* GraphQL
* Postman

## Features:
* GraphQL API: implementation of access points for data retrieval and modification
* CRUD operations: create, read, update and delete entities via GraphQL queries
* Query optimization: eliminating the N+1 problem using DataLoader
* Limiting query nesting and protecting against redundant data
