**Stack:** CMS ModX + MiniShop2 + Fenom, HTML, SCSS, PUG, Webpack, JavaScript, jQuery, Swiper.js, PhotoSwipe.js, PHP  
**ModX Packages:** MiniShop2, ClientConfig, FetchIt, pdoTools, reCaptchaV3, Translitor

**Project Description:**
Website catalog with products for a company specializing in the sale of radio electronic components. The main task was a complete transfer of the site from the Creatium builder to CMS ModX.

**My role:**  
- Adaptive and mobile site layout
- Stretching the layout on ModX
- Customization of modal windows and feedback form
- Designing site structure in ModX
- Realization of copies of the site for different countries and on different hosting sites

**Key Features:**  
- Flexible ways to display products (cards/table)
- Interactive product galleries (Swiper.js, PhotoSwipe.js)
