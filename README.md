# Letra

**Stack:** PHP, cURL, DiDOM, Composer, Google Programmable Search Engine, PhpSpreadsheet, cron, Excel, XML, YML

**Project Description:**
Creation of a data parser from the source and generation of Excel, XML and YML files from this data. The main task was to automate the process of parsing and converting data into the required formats.

**My role:**
- Developing a parser of data from the source site with data saving in Excel, XML, YML formats
- Placing the parser on the server and setting up `cron` for its periodic execution  
- Integration of Google Programmable Search Engine into the site  

**Key features:**
- Automated data collection from an external site  
- Saving data in various formats (Excel, XML, YML)  
- Customized `cron` for periodic data updates  
- Google search integration into the site
