# Zennek

[zennek.parts](https://zennek.parts/)

**Stack:** CMS ModX, VPS (Linux Ubuntu), HTML, CSS, JavaScript, AJAX, PHP, Laximo API    
**ModX Packages:** Minishop2, ClientConfig, Console, FetchIt, MIGX, msaddfield, mSearch2, msMCD, pdoTools, Translitor, mFilter2  

**Project Description:**
Development and refinement of online store of auto parts, customization of product search by article and VIN, integration with Laximo API, migration and server configuration, multi-lingualism.  

**My role:**  
- VPS server setup: DB installation, PHP, SSL configuration, CMS ModX installation  
- Stretching of layout on CMS ModX  
- Installation and customization of mSearch2  
- Import of goods with pictures and customization of product cards  
- Finalization of page layout: Home, product cards, news cards  
- Realization of search by article and cross-keys  
- Integration of VIN search via Laximo API with AJAX data rendering  
- Search by number and VIN in header with input validation  
- Customizing form sending to email  
- Adding and displaying search hints  
- Transfer site to another server with environment customization  
- Customizing 404 page  
- Realization of multilingualism (Russian + English versions of the site)  
- Realization of viewing statistics of site visits in the admin area  
- Exporting data about products in English to .csv  
- Recording video tutorials on working with products 
- Setting captcha for VIN search via Laximo API  
- Localization of Laximo API errors to the required language  

**Key Features:**  
- Integration with Laximo API for parts search by VIN, article and cross-keys  
- Dynamic rendering of Laximo API data via AJAX  
- Full multi-language (Russian/English)  
- Ability to import products with images
