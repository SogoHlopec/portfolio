# REST Service (Home Library Service)
The project is a REST service for managing personal media library (Home Library Service), where users can create, view, edit and delete data about tracks, albums and artists, as well as add them to Favorites. This project was created while studying at RS SHOOL https://rs.school/ NodeJS 2024Q3.

## Stack:
* Node.js
* Nest.js
* REST API
* TypeScript
* Postman
* OpenAPI
* Swagger
* Docker + Docker Compose
* WSL + Linux Ubuntu
* PostgreSQL
* Prisma
* JWT

## Features:
* REST API: implementation of CRUD operations for user, artist, album and track entities
* Database customization and interaction via Prisma ORM
* Deploy and run all services via Docker Compose
* JWT authentication and authorization, registration, login and update tokens, API route protection with access and update tokens
* API documentation with Swagger
* Log collection and error monitoring
