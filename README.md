# Laminar

[laminar.by](https://laminar.by/)

**Stack:** CMS ModX, HTML, SCSS, PUG, JavaScript, jQuery, Webpack, PhotoSwipe.js, Swiper.js, Inputmask.js  
**ModX Packages:** ClientConfig, FetchIt, MIGX, pdoTools, reCaptchaV3, Translitor

**Project Description:**
Corporate multi-page website for a company specializing in industrial refrigeration equipment. The main task was to create a site on ModX with data migration from the old site.

**My role:**
- Layout and adaptation of design for mobile devices
- Website structure design in CMS ModX
- Hosting and domain setup
- Protecting forms from spam and customizing their work
- Realization of AJAX data loading for modal windows
- Integration with Google Sheets for automatic rendering of data on product availability
- Development of periodic Google Sheets parser
- Development of pages with dynamic data update
- Implementation of “Load More” button for dynamic rendering of products
- Recording video tutorials on working with the site

Translated with DeepL.com (free version)

**Key features:**
- Fully responsive layout
- Forms spam protection with reCaptchaV3
- AJAX content loading for improved UX
- Automatic synchronization of product data with Google Sheets
- Limit product loading for optimized performance
