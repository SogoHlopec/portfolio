# STH

[sth.by](https://sth.by/) | [lebrama.site](https://lebrama.site/) (test site, in progress)

**Stack:** CMS WordPress, HTML, CSS, JavaScript, PHP, jQuery, CMS Joomla + ZOO, Google Sheets API, Yandex Map API, Telegram API
**WP plugins:** WPBakery, Toolset, Really Simple CSV Importer, Duplicator

**Project Description:**
Corporate website of the company providing services of installation of heating systems. The main task was to transfer a copy of the old site to WordPress and its finalization.

**My role:**  
- Transferring a copy of the site to a new hosting, setting up the domain  
- WordPress update, code cleanup  
- Page layout using Toolset + WPBakery  
- Exporting products and categories to CMS Joomla
- Customizing the feedback form
- Connecting and customizing Yandex Map API
- Importing goods to WP
- Getting EUR exchange rate from NBRB API and converting prices to BYN
- Realization of parsing prices from source sites and saving data to Google Sheets API.
- Setting up periodic parsing of goods from source sites
- Setting up notifications in Telegram about the status of parsing
- Synchronization of product prices between Google Sheets and website
- Email layout, creating a template page for Instagram posts
- Improvement of the calculator functionality for calculating the cost of installation of heating systems

**Key features:**  
- Full-fledged site migration with preserved functionality  
- Automated parsing of prices and products from source sites  
- Periodic price synchronization system via Google Sheets API  
- Improved layout and site adaptability  
- Interactive Yandex map
- Heating system installation cost calculator
